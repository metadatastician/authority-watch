== Unreleased

=== Core Ontology and Safety Boundary (2026-07-XX)

* Establish the generic authority/change ontology:
  ** AuthorityGrade (FormalPrimary, FormalProfessional, OfficialGuidance, Prospective, SecondaryCommentary)
  ** ReviewState (37 states for document lifecycle)
  ** Freshness (9 states for source health)
  ** TemporalFacts (17 legal date fields)
* Define strict safety boundary: observation ≠ interpretation ≠ approval ≠ publication
* Implement non-bypassable review state transitions via `canAdvance()`
* Implement bundle activation gates via `canActivate()` with 8 simultaneous conditions

=== Zig Manual Precision Core (2026-07-XX)

* Add Zig executable (`authority-watch`) with three commands:
  ** `status` — Show system state and configuration
  ** `freshness <profile>` — Check profile freshness status
  ** `ingest <file>` — Compute SHA-256 digest of official source file
* Implement SHA-256 digest computation using Zig standard library
* Add unit tests for digest uniqueness and review state transitions
* Add type definitions mirroring Idris2 domain model

=== Initial Profile: UK Insolvency (2026-07-XX)

* Add `uk-insolvency` profile with full configuration:
  ** Profile manifest (PROVISIONAL_UNREVIEWED status)
  ** Source registry (7 sources: legislation.gov.uk, GOV.UK, UK Parliament, SIP, JIEB, Gazette, Find Case Law)
  ** Watchlist (Insolvency Act 1986, CDDA 1986, IEWR 2016, CIGA 2020)
* All sources configured with:
  ** Authority grade (A, B, C, D)
  ** Jurisdiction and coverage
  ** Official and machine URIs
  ** Licence terms (REVIEW_REQUIRED where applicable)
  ** Retrieval method and expected cadence
  ** Enabled = false (all monitoring disabled)

=== Estate Reconciliation (2026-07-XX)

* Record capability findings for estate integrations:
  ** Gossamer: AffineScript bindings exist, integration staged
  ** typed-wasm: Intended verified carrier, integration capability-gated
  ** zig-unified-hexadeca-api: CORRECT estate API (previously `zig-unified-hexadeca-adapter`), may be in `boj-server` or `developer-ecosystem` (NOT in rsr-template-repo)
  ** unified-hexadeca-api: BLOCKED — no canonical repository located, DO NOT USE
  ** SNIFS: BEAM/Wasm safety design not currently needed
  ** No-Nonsense NNTPS: Reader/profile integration only
  ** proven-tests-and-benches: Idris2 test taxonomy reusable

* **ARCHITECTURE CLARIFICATION:**
  ** FFI is PURE ZIG (no C intermediary)
  ** ABI is PURE IDRIS2 (no C intermediary)
  ** Estate API is `zig-unified-hexadeca-api` (in hyperpolymath estate, possibly `boj-server`)

== v0.1.0 — Foundation Release (Planned: 2026-08-XX)

This is the first tagged release. It establishes the foundation for:

* Manual precision core with strict safety invariants
* Complete domain model for legal document monitoring
* RSR-compliant repository structure
* Comprehensive documentation (README, EXPLAINME, AFFIRMATION, AUDIT, GOVERNANCE)
