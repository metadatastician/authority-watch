= Dependencies

[cols="1,1,3",options="header"]
|===
|Dependency |Status |Boundary

|AffineScript
|Experimental
|Principal application contracts only; do not assume unimplemented compiler
or standard-library capabilities.

|Zig 0.16
|Available
|Executable core, acquisition, hashing, storage, signatures, protocol and FFI
boundaries. No C intermediary.

|Idris2 0.7
|Available
|Identity, transition, temporal and activation invariants.

|typed-wasm
|Inspected
|Intended verified carrier; integration remains capability-gated.

|Gossamer
|Inspected
|AffineScript bindings and pure-Zig shell exist; operator console integration
is staged after the manual core.

|SNIFS
|Inspected
|No dependency selected. Its BEAM/Wasm safety design is not presently needed
for the canonical observation ledger.

|No-Nonsense NNTPS
|Inspected
|Reader/profile integration only; Authority Watch will not turn it into a
server.

|proven-tests-and-benches
|Inspected
|Idris2 test taxonomy is reusable; direct package integration is deferred
until the initial core ABI stabilises.

|unified-hexadeca-api
|Blocked
|No canonical repository was located. No API is invented in its absence.
