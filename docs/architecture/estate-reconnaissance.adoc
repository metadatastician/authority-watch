2026-07-29. Revisions below identify the exact inspected state. Dirty or
diverged estate checkouts were not modified.

== Unresolved estate capabilities

No canonical repository for `unified-hexadeca-api` was located. The inspected
`sim-insolvency` revision independently records the same blocker. Authority
Watch therefore documents a read-oriented API contract but does not fabricate
an implementation or dependency.

The estate template chain is documented as
`standards -> rsr-template-repo -> scaffoldia`. The directly inspected
`sim-insolvency` repository is the closest current architecture template for
this project.

== Integration choices

* The offline core precedes all automated acquisition.
* Source adapters return immutable observations; they never return rule edits.
* Gossamer receives a projection and authenticated commands, not direct access
  to signing keys.
* `sim-insolvency` receives verified bundles and freshness metadata, never live
  source-adapter output.
* NNTPS and Burble mirror review evidence but cannot advance canonical state.
* Missing capabilities fail closed and remain visible in status output.
