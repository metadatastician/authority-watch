# Security policy

Report vulnerabilities privately through the repository's GitHub security
advisory interface.

Do not include source archives, credentials, signing keys, private review
records, personal data, or exploitable adapter details in a public issue.

Compromise of an online signing role does not compromise the offline root.
Affected keys and bundles must be revoked through a new signed revocation
record; historical evidence must not be destructively rewritten.

This initial repository contains no production trust root and no production
signing key.
